# AWS Machine Learning Services (High-Level)

## Overview
AWS offers managed ML services that are tested at a high level on the SAA exam. Know what each service does — not how to build models.

## Service Catalog

| Service | Purpose |
|---------|---------|
| Amazon Rekognition | Image and video analysis (faces, objects, text, celebrities) |
| Amazon Transcribe | Speech to text (audio transcription) |
| Amazon Polly | Text to speech (natural sounding) |
| Amazon Translate | Language translation |
| Amazon Lex | Chatbots (speech recognition + NLU, powers Alexa) |
| Amazon Comprehend | NLP — sentiment analysis, entity extraction, topic modeling |
| Amazon Textract | Extract text and data from scanned documents (OCR+) |
| Amazon Kendra | Intelligent enterprise search (ML-powered) |
| Amazon SageMaker AI | Build, train, and deploy ML models (full platform) |

## When to Choose Each

| Requirement | Service |
|-------------|---------|
| Detect faces in images | Rekognition |
| Convert audio to text | Transcribe |
| Read aloud text content | Polly |
| Translate between languages | Translate |
| Build a chatbot | Lex |
| Analyze text sentiment | Comprehend |
| Extract data from forms/documents | Textract |
| Search across documents | Kendra |
| Custom ML model | SageMaker |

## Exam Tips
- Know the purpose of each service (one sentence per service)
- These are usually straightforward "which service does X?" questions
- Rekognition for images/video, Textract for documents
- Lex = chatbot (not just speech), Transcribe = speech-to-text
- Kendra for intelligent document search
- SageMaker for custom ML (mentioned rarely on SAA)
